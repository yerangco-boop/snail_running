# 달팽이 러닝 UI 개편 — 이미지 작업 정리 (2026-11-02)

기준 자료: `Documents\달팽이_디자인_이미지`(저장소 밖 비공개 폴더), `docs/design_tokens.md`, Claude 메모(project_ui_redesign_decisions).
이 문서의 작업 항목 번호(H·C)는 11/02에 결정 사항을 바탕으로 다시 나눈 것이며, 이전 T1~T16 번호와 1:1 대응하지 않는다.

## 1. 이미 만든 것

| 항목 | 상태 |
|---|---|
| 기준 시안 (1번, 코랄·크림·후드 달팽이) | 있음, 이게 기준 |
| 확정 달팽이 시트 (정면 + 응원 춤 6포즈) | 매끈한 3D 렌더. 점토 재질 아님 |

| 앱 코드 (`ui-redesign` 브랜치) | 밝은 단일 룩, 색 토큰, 대비 정리, 시작 버튼 링, 이력 기간 선택. main 미병합 |
| `docs/design_tokens.md` | 1번 시안 실측 색 기준 |

| # | 항목 | 비고 |
|---|---|---|
| H1 | 점토 달팽이 마스터 (정면) | 모든 작업의 기준. 매끈·통통하되 날렵, 두껍거나 거칠지 않게 |

## 3. 아직 확정 안 된 결정

1. 코랄 색 3단계(면 / 큰 글자 / 작은 글자) 앱 전체 적용 전 최종 확인
2. 지도 표현 (초록 공원·나무 오버레이 여부)
3. 실패 동작의 톤이 압박감 없는지
4. 부분 점토 vs 전체 점토 (현재 의견: 부분 점토 = 달팽이·경로선·버튼만)

1. 힉스필드 H1 점토 달팽이 마스터 → 합격해야 다음으로
