# 화면 켬/끔 비교 테스트 (2026-10-27, v37 측정 수정 검증)

목표: 화면 상태·사용 습관과 무관하게 같은 값. **합격 기준: 총 거리 차이 3% 이내, 바퀴 수 동일.**

## 준비
- 같은 코스(길이를 아는 운동장 한 바퀴)에서 **같은 시작점**에서 시작. 바퀴 수는 직접 세어 둘 것(예: 6바퀴).
- 페이스는 비슷하게(슬로우 조깅). 폰은 평소처럼 손에 쥠.
- 설정 → 실외 테스트 로그 공유로 매번 로그를 복사해 `Documents\달팽이_러닝기록\로그`에 저장.

## 순서 (총 3회, 각 6바퀴 ≈ 2km / 20분)
1. **B. 시작하자마자 화면 끄고 끝까지** — 가장 어려운 경우를 먼저(저장된 보폭으로 시작하는지 확인)
2. **A. 화면 계속 켬** — 기준값
3. **C. 한 바퀴마다 껐다 켰다** — 평소 습관

각 러닝 후 이력 상세에서 거리·바퀴·걸음 수 캡처.

## 판정
| 항목 | 합격 |
|---|---|
| B·C 총 거리 vs A | ±3% 이내 |
| B·C 바퀴 수 vs 직접 센 바퀴 | 같음 |
| 걸음 수 | B·C가 A와 ±5% 이내 |

## 로그에서 볼 줄 (수정이 실제로 작동했는지)
- `[STRIDE] 지난 기록 N건으로 보폭 모델 초기화` — 첫 실행 때 한 번
- `보폭=…cm(저장값)` — 이번 러닝에서 아직 못 배운 시점에 저장값을 쓰는 중
- `[LAP] 저장된 한 바퀴 거리 …m 적용` — 같은 코스에서 시작해 처음부터 거리 기반 바퀴
- `[GPS] 튐 제외 …` — 튄 점을 경로에서 뺀 기록
- `[GPS] 제자리(걸음 없음) …` — 서 있는 동안 GPS 흔들림을 거리에 안 넣음

## 책상 위 테스트
폰을 책상에 두고 러닝 시작 → 5분 → 종료. 기대: **0.00km**, 이력에 저장 안 됨.

## 알려진 한계
- 지금까지 걸어서(105spm) 화면을 켠 채 GPS가 좋았던 기록이 없으면 걷기 보폭은 모름 — 처음 걷기는 걸음당 1.0m 상한만 적용. 걷기를 한 번 화면 켜고 하면 그 뒤로 저장됨.
- 화면이 꺼진 구간의 지도 경로선은 아직 점선/직선 표시 없이 비어 보일 수 있음(거리·바퀴 값에는 영향 없음).
