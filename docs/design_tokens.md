기준: 1번 시안(크림 배경 + 코랄 주황), 밝은 단일 룩. 대비는 WCAG 상대휘도 공식으로 직접 계산한 값

## 1. 코랄 3단계

| 토큰 | 값 | 크림 #FFF6EC 위 | 흰 #FFF 위 | 용도 |

| `coralFace` | #F57A51 | 2.52 | 2.70 | **면 전용**(버튼 바탕·칩·진행 막대). 글자·얇은 아이콘 금지 |
| `coralStrong` | #D9501E | 3.84 | 4.10 | 큰 글자(24px 이상)·굵은 아이콘·테두리 (3:1 기준 통과) |
| `coralText` | #B8420F | 5.14 | 5.49 | 작은 글자·링크 (4.5:1 통과). 흰 글자를 올리는 면으로도 가능(5.49) |

- 사용자가 어둡다고 한 #C2410C(4.84)는 `coralText`(5.14)와 거의 같은 밝기대라, `coralText`는 그보다 살짝 밝은 대신 4.5를 여유 있게 넘기는 값으로 잡음.
  **작은 글자는 코랄을 쓰지 않고 검정으로 가는 선택지도 항상 열려 있음.**
- `coralFace` 위 글자: 검정 #1A1A1A **6.45** 통과 / 흰색 **2.70 실패**.

## 2. 현재 코드에서 걸리는 지점 (실제 확인)

`Colors.white`를 코랄 면(`_s.accent`) 위에 얹는 곳이 있음 — 면이 #F57A51이면 2.70으로 기준(그래픽 3:1, 글자 4.5:1) 미달:
- `home_screen.dart:1864` 시작 버튼 재생 아이콘(52px), `:2287` 일시정지, `:2327` 재개, `:2522` 버튼 글자, `:2555`·`:1591` 선택 칩 글자
- 해결 선택지: ① 면 위 글자·아이콘을 `inkOnCoral`(#1A1A1A)로 ② 버튼 면을 `coralText`(#B8420F)로 하고 흰 글자(5.49). **①이 시안 코랄을 그대로 살림**(권장)

## 4. 구조안 (코드 반영 시)

- 현재 `ThemePreset`은 다크 5종 + `onBackground` 등을 **밝기로 자동 계산**하는 구조. 단일 룩으로 가면 자동 계산을 없애고 위 토큰을 **명시 값**으로 둠(자동 계산이 만든 가독성 버그 이력이 있음).
- 새 파일 `lib/theme/tokens.dart` 한 곳에 색·글자 6단계·간격(버튼 간 16px)·최소 터치 크기(주행 56/일반 48)를 정의, 화면 파일은 토큰만 참조.
- 화면 파일의 `Colors.*` 직접 사용 약 30곳(위 grep 기준: home 약 20, history 3, settings 2, route_utils 10)을 토큰으로 치환. `route_utils`의 흰 테두리·검정 그림자는 지도 위 표식이라 토큰화하되 값은 유지.
- `app_theme.dart`는 어디서도 import되지 않는 레거시 → 새 구조 도입 때 삭제 후보(지금은 건드리지 않음).
- 기존 5종 다크 프리셋·설정 화면 테마 선택 UI는 "단일 룩" 결정에 따라 제거 대상이나, **저장된 `preset` 이름 설정(SharedPreferences)과의 호환**을 구현 때 처리해야 함.
